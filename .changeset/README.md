# Changesets

Each user-facing change includes a Changeset with the package name, version bump, and
release note.

```bash
npx changeset
```

Use a conventional commit line as the first line of the note. Keep implementation
details in bullets when they help package users.

See the [Changesets documentation](https://github.com/changesets/changesets/tree/main/docs)
for file format and release flow details.
