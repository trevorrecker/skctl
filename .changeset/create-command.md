Add `skctl create skill|command` to scaffold a new source file into the configured scope with valid frontmatter and a starter body. Runs one-shot from flags (`-d`, `--body`/`--body -`, `--hosts`, `--argument-hint`, `--apply`, `--force`) or prompts for name and description in a terminal. New skills default to `paste: true`.
